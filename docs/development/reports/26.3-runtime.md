# Paper 26.3 runtime compatibility

## Scope

This report covers an isolated local runtime check of the GoldBag release
artifact against official Paper 26.3. It does not change production files or
the tracked player-smoke harness. The runtime directory was
`/tmp/goldbag-26.3-runtime`; the server was bound to `127.0.0.1:25576` and is
stopped at the end of the check. The local test was authorized with
`eula=true`.

## Exact platform and artifacts

- Host: Linux `7.0.0-38-generic`, amd64.
- Java: Eclipse Temurin `25.0.4.1+1` LTS, downloaded from the Adoptium API and
  run from `/tmp/goldbag-26.3-runtime/jdk/jdk-25.0.4.1+1/bin/java`.
- Paper: official stable `26.3-175`, commit `bd9daa8fba19cb288d690c1621ad1749de3e0a78`,
  published `2026-10-11T15:32:14Z`, implementing API
  `26.3.build.175-stable`.
- Paper download URL:
  `https://fill-data.papermc.io/v1/objects/ece5afb6d0cdf0c930489618bf92341e33d2ebcd4f21e6d365daff6ed26dafb0/paper-26.3-175.jar`
- Paper SHA-256: `ece5afb6d0cdf0c930489618bf92341e33d2ebcd4f21e6d365daff6ed26dafb0`
  (matched the official Paper build metadata).
- Tested release artifact: `/tmp/goldbag-release-build/dist/GoldBag-2.0.0.jar`.
- Release artifact SHA-256:
  `55dc7ba1a47280a293cb8249cdbf9d57b9e6e80de622583f584e4fdcea121668`.

The server was started with:

```text
/tmp/goldbag-26.3-runtime/jdk/jdk-25.0.4.1+1/bin/java -Xms512M -Xmx2G -jar paper-26.3-175.jar --nogui
```

## Results

- PASS: Paper 26.3 build 175 started on Java 25 and listened on
  `127.0.0.1:25576`.
- PASS: Paper discovered and enabled `GoldBag v2.0.0` without an exception.
- PASS: GoldBag initialized SQLite storage and all 18 configured resources.
- PASS: Console `goldbag rates` listed the catalog, including raw iron and its
  storage block.
- PASS: Console `goldbag storage status` reported healthy storage with zero
  pending operations.
- PASS: Console `goldbag storage export` wrote
  `plugins/GoldBag/goldbag-export.json`.
- PASS: Console `goldbag reload` reloaded configuration and expired pending
  quotes.
- PASS: `stop` completed a clean shutdown, including GoldBag disable and world
  chunk saves; port 25576 closed.
- PASS: A second clean start using the same release artifact and SQLite data
  enabled GoldBag again, and `goldbag storage status` again reported healthy
  storage with zero pending operations.
- PASS: The second run also stopped cleanly. `eula.txt` remains `eula=true`.

Relevant logs are preserved in the isolated directory:

- `/tmp/goldbag-26.3-runtime/logs/server-release.log`
- `/tmp/goldbag-26.3-runtime/logs/server-release-restart.log`

## Player-smoke compatibility

The existing loopback Mineflayer smoke could not reach login on Paper 26.3.
With the pinned dependency set (`mineflayer 4.38.0`), the client reported:

```text
Unsupported protocol version '777'; try updating your packages with 'npm update'
```

The newest npm release available during this check, Mineflayer `4.39.0` with
`minecraft-protocol 1.68.0`, also failed before login:

```text
No data available for version 26.3
```

The installed `minecraft-data` package had no 26.3/protocol-777 entry. This is
an external test-client data gap, not a GoldBag startup or Bukkit API failure.
No player deposits, menus, notes, or inventory flows are certified for Paper
26.3 by this report. The harness should remain pinned until a Mineflayer
release adds 26.3 support, then be rerun against this server version.

## Compatibility conclusion

No GoldBag source compatibility fix was identified from the Java 25/Paper 26.3
startup, storage, catalog, export, reload, restart, and shutdown checks. The
release artifact is runtime-compatible for the exercised server lifecycle and
console/storage paths. Full player-flow compatibility remains unverified solely
because the available Mineflayer protocol data does not support Minecraft 26.3.
