## Compatibility and remaining limitations

The live Paper investigation is in [26.3-runtime.md](26.3-runtime.md). The existing public Spigot 1.17 API remains the compile target; no observed runtime failure justified dropping older compatibility. Java 25 was added to build/package verification rather than raising plugin bytecode unnecessarily.

The protocol harness cannot validate live 26.3 players: both pinned Mineflayer 4.38.0 and latest tested 4.39.0 lack 26.3 data. Inventory exchange, payments, menus and banknote interactions require manual testing with an actual client or a protocol-library update. Earlier 1.21.11 player evidence is not presented as a 26.3 result.

The root release-tooling dependency audit reports 13 vulnerabilities (11 high, two moderate) in upstream braces/micromatch and bundled npm dependencies. `npm audit fix --ignore-scripts` did not remove them; a forced downgrade would change semantic-release behavior and was not applied. These packages do not enter the shaded Minecraft plugin. Build and release analysis checks pass, but the audit is not clean.

The release job's built-in Actions token has not actually published a release before merge; the dry-run uses connected account authentication. Production release publishing remains intentionally unexercised in this PR. Scoped independent review found mutable Actions refs and a nondeterministic release timestamp; both were corrected and re-reviewed clear in [26.3-release-review.md](26.3-release-review.md).
